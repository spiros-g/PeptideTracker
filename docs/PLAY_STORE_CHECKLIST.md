# Google Play checklist

- Preserve application ID `gr.peptidetracker.app` and increment versionCode.
- Target API 36 for submissions from 31 August 2026.
- Configure an external upload key and generate an AAB.
- Publish an accurate privacy policy and complete Data Safety, Health Apps, ads and content declarations.
- Review INTERNET and network permissions; no tracker data leaves the device.
- Add store listing, screenshots, support contact and testing instructions.
- Complete required internal/closed testing before production.
- Verify UMP consent and production AdMob IDs on a test device.
